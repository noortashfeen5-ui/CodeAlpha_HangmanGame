# CodeAlpha_HangmanGame 🎯

A sleek, interactive **Hangman Game** built with **Python**. Test your word-guessing skills in real-time!

## 🚀 Quick Start
Run `hangman_game.ipynb` directly in **Google Colab** or **Jupyter Notebook** to start playing.

## ✨ Features
- 🎲 Random word generation
- 📊 Interactive attempt tracker
- ⚡ Lightweight & easy to run
